# Saiket Systems - Software Development Internship (Level 1)

Welcome to my repository for **Level 1** tasks completed during my Software Development Internship at **Saiket Systems**. 

## 📂 Project Structure & Tasks

* **Task 1: Loan EMI Calculator** (`Task_1_Loan_EMI_Calculator.py`)
  * A Python program that calculates the monthly Equated Monthly Installment (EMI) based on principal amount, interest rate, and loan tenure.

* **Task 2: Public API Fetcher** (`Task_2_Fetch_API_Data.py`)
  * A Python script that connects to a public REST API to fetch and display live data dynamically.

* **Task 3: Simple Blog App** (`Task_3_Simple_Blog_App/index.html`)
  * A frontend web application built with HTML, CSS, and JavaScript featuring CRUD operations and data persistence via browser `localStorage`.

* **Task 4: Number Guessing Game** (`Task_4_Number_Guessing_Game.py`)
  * An interactive command-line Python game where the user guesses a randomly generated number with feedback hints.

* **Task 5: Simple Contact Book** (`Task_5_Simple_Contact_Book.py`)
  * A structured Python console application to add, view, search, and delete contact details.

## 🛠️ Technologies Used
* **Python** (Core logic and CLI applications)
* **HTML5, CSS3, JavaScript** (Frontend Blog Application)
* **Git & GitHub** (Version control and code storage)
